# Cardápio Maresia

Cardápio do Maresia lounge bar, publicado via GitHub Pages. Página única: `index.html` (+ `img/` com as 3 imagens que ela usa).

- Desenvolvimento na branch `dev`; `main` é o que vai ao ar.
- Para gerar o PDF: abrir no Chrome > Cmd+P > Salvar como PDF, margens "Nenhuma", marcar "Gráficos de plano de fundo".
